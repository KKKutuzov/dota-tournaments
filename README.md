# Турниры · Dota 2

Дашборд с расписанием матчей по Dota 2 для нескольких турниров: ближайший матч с
обратным отсчётом, счёт, трансляции, турнирные таблицы и сетки плей-офф. Есть режим
«Мои матчи» с подсветкой своих команд и приоритетом матчей.

Статичный сайт без сборки (vanilla HTML/CSS/JS). Данные турниров на Google Таблицах
читаются в браузере напрямую; данные ЛЧБ собираются скриптом в `data/lchb.json`.

## Возможности

- Геро-карточка «Ближайший матч» с живым обратным отсчётом и авто-обновлением данных.
- Матчи по дням, метки LIVE/сегодня, счёт с подсветкой победы (зелёный) и поражения (красный).
- Трансляции (Twitch) у предстоящих матчей; ссылка на страницу матча у ЛЧБ.
- Турнирные таблицы групп; ссылки на лиги Dotabuff.
- **Режим «Мои матчи»** (по умолчанию, тумблер в шапке): только свои матчи, подсветка команд
  меткой «Я», приоритет матчей (замена в Комусе уступает Сберу/ЛЧБ при совпадении по времени),
  гипотетический путь по сетке плей-офф.
- Фильтры по турниру, «только предстоящие», поиск; адаптив под телефон.

## Источники данных

| Турнир | Источник | Обновление |
|--------|----------|------------|
| Спартакиада Комус 2026 | Google Таблица (CSV export) | в браузере, live |
| Сбер 2026 | Google Таблица (CSV export) | в браузере, live |
| ЛЧБ · Весна 2026 (лига Изумруд) | dota.businesschampionsleague.com | `scrape_lchb.py` → `data/lchb.json` |

Google отдаёт `Access-Control-Allow-Origin: *`, поэтому таблицы читаются из браузера
напрямую. Сайт ЛЧБ CORS не отдаёт — его данные собирает Python-скрипт (см. ниже),
автоматически по расписанию через GitHub Actions.

## Структура

```
├── index.html          разметка
├── styles.css          стили (тёмная тема)
├── app.js              загрузка данных, рендер, режимы, таймер
├── parser.js           разбор Google-таблиц (CSV → матчи + таблицы), без DOM
├── scrape_lchb.py      сбор данных ЛЧБ → data/lchb.json
├── requirements.txt    зависимости скрапера
├── data/
│   ├── lchb.json       данные ЛЧБ (генерируется скрапером)
│   └── *.csv           офлайн-снимки Google-таблиц (фолбэк)
├── test_parser.js      тесты парсера (node)
├── test_render.js      smoke-тест рендера (node)
└── .github/workflows/update-lchb.yml   авто-обновление ЛЧБ
```

## Локальная разработка

```bash
python -m http.server 8000      # http://localhost:8000
```

Локальный сервер нужен, чтобы браузер мог прочитать `data/lchb.json`.

Тесты:

```bash
node test_parser.js
node test_render.js
```

## Обновление данных ЛЧБ

```bash
pip install -r requirements.txt
python scrape_lchb.py           # перезапишет data/lchb.json
```

Скрипт парсит лигу Изумруд (расписание группы + таблица + трансляции). В проде это
делает GitHub Actions по расписанию (`.github/workflows/update-lchb.yml`), коммитя
обновлённый `data/lchb.json`.

## Деплой

GitHub Pages: ветка `main`, папка `/` (root). Для авто-обновления ЛЧБ в настройках
репозитория включить Actions → Workflow permissions → Read and write.

## Конфигурация

- `MY_TEAMS`, `PRIORITY` (app.js) — свои команды и приоритет турниров.
- `TOURNAMENTS` (app.js) — турниры, листы Google (`gid`), ссылки Dotabuff.
- `LEAGUE`, `MY_TEAM` (scrape_lchb.py) — лига и команда ЛЧБ.
- `YEAR`, `MSK_OFFSET` (parser.js) — год турниров и часовой пояс.
