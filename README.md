# Турниры · Dota 2 🏆

Современный сайт-дашборд с расписанием турниров по Dota 2: когда матч, какие команды,
счёт и трансляция. Подходит, чтобы показать кому угодно — по умолчанию это **общее расписание**.

## Что умеет

- ⏳ **Геро-карточка «Ближайший матч»** с живым обратным отсчётом.
- 🔄 **Живое обновление**: данные сами подтягиваются каждые ~2 минуты (и при возврате на вкладку).
- 📅 Все матчи по дням (сегодня подсвечено), метка LIVE для идущих сейчас.
- ✅ Счёт сыгранных матчей: победа — зелёным, поражение — красным.
- 📺 **Трансляция** (Twitch) у будущих матчей; **ℹ подробнее** у сыгранных матчей ЛЧБ — ссылка на страницу матча.
- Ссылки на лиги Dotabuff — в подвале.
- 📊 Турнирные таблицы (группы) — сворачиваемые.
- 🔎 Фильтры: по турниру (сегментированный переключатель), «только предстоящие», поиск по команде.
- 📱 Адаптив под телефон.

### Режим «Мои матчи» (включён по умолчанию, тумблер в шапке)

Личный режим для владельца — **включён по умолчанию**; тумблером можно переключить на «Все»,
состояние запоминается. В нём:
- показываются **только мои матчи**, мои команды подсвечены золотом и меткой «Я»;
- работает **приоритет**: Комус — замена, поэтому при совпадении по времени со Сбером/ЛЧБ
  матч Комуса помечается «⏭ замена · играю в …», а тот, что играю — «★ мой матч»;
- **гипотетический путь по сетке**: будущие матчи плей-офф, куда я попаду, если пройду дальше,
  показываются пунктиром с моей командой в слоте — «🔮 если пройду дальше» / «🥉 если проиграю»;
- баннер сверху: ближайший мой матч, с кем и через сколько.

Подсветка результата (в любом режиме): победа — зелёным, поражение — красным.

Команды владельца (задаются в `MY_TEAMS` в `app.js`):
**SZW** — Комус (замена), **CA_UNLIMITED** — Сбер, **TeamSpirt** — ЛЧБ (Изумруд).

## Откуда берутся данные

| Турнир | Источник | Как обновляется |
|--------|----------|-----------------|
| Спартакиада Комус 2026 | Google Таблица | **живьём** в браузере (Google отдаёт CORS) |
| Сбер 2026 | Google Таблица | **живьём** в браузере |
| ЛЧБ · Весна 2026 | сайт businesschampionsleague.com | через скрипт `scrape_lchb.py` → `data/lchb.json` |

Сайт ЛЧБ **не разрешает** браузеру читать себя напрямую (нет CORS-заголовка),
поэтому его данные забирает Python-скрипт и кладёт в `data/lchb.json`, который читает сайт.

## Структура

```
dota_tournaments/
├── index.html       разметка
├── styles.css       тёмный Dota-дизайн
├── parser.js        разбор Google-таблиц (CSV → матчи + таблицы), без DOM
├── app.js           загрузка данных (Google + lchb.json), рендер, таймер, приоритет
├── scrape_lchb.py   сборщик данных ЛЧБ (лига Изумруд) → data/lchb.json
├── data/
│   ├── lchb.json    данные ЛЧБ (генерит scrape_lchb.py)
│   └── *.csv        снимки Google-таблиц (fallback, если Google недоступен)
├── test_parser.js   тест парсера (node)
└── test_render.js   smoke-тест рендера (node)
```

## Запуск локально

```powershell
# 1) (по желанию) обновить данные ЛЧБ
python scrape_lchb.py

# 2) поднять локальный сервер из папки проекта
python -m http.server 8000
# открой http://localhost:8000
```

> Сервер нужен, чтобы браузер мог прочитать `data/lchb.json` (локальный файл).
> Google-турниры подтягиваются и так. Остановить сервер — Ctrl+C.

## Обновление данных ЛЧБ

```powershell
python scrape_lchb.py
```

Скрипт скачивает страницы ЛЧБ, парсит лигу **Изумруд** (расписание группы + таблицу,
с пометкой команды TeamSpirt) и перезаписывает `data/lchb.json`. После этого обнови
страницу сайта. Нужны пакеты: `pip install requests beautifulsoup4`.

Кнопка **«Обновить»** на сайте перечитывает Google-таблицы и `lchb.json` без перезагрузки,
но сам файл `lchb.json` обновляется только скриптом.

## Выложить онлайн (бесплатно)

Сайт статичный. Перед заливкой запусти `scrape_lchb.py`, чтобы `data/lchb.json` был свежим.

- **Netlify Drop** (быстро): https://app.netlify.com/drop — перетащи папку, получишь ссылку. ЛЧБ обновляешь вручную (скрипт + перезалив).
- **Vercel**: импорт репозитория / `vercel` в папке.

### GitHub Pages + авто-обновление ЛЧБ (рекомендуется)

Без установки git — через веб-интерфейс GitHub:

1. Зарегистрируйся на github.com, нажми **New repository** → имя (напр. `dota-tournaments`), **Public** → Create.
2. На странице репозитория: **Add file → Upload files** → перетащи всё содержимое папки `dota_tournaments`
   (включая папку `.github`) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
   Через минуту сайт будет на `https://ИМЯ.github.io/dota-tournaments/`.
4. **Settings → Actions → General → Workflow permissions** → выбери **Read and write permissions** → Save
   (чтобы Action мог коммитить свежий `lchb.json`).

Готово: воркфлоу `.github/workflows/update-lchb.yml` сам пересобирает ЛЧБ 4 раза в день
(и по кнопке **Run workflow** во вкладке Actions), а Pages пере-публикует сайт.
Google-турниры и так живые. Обновлять что-либо вручную больше не нужно.

## Настройка

- **Мои команды и приоритет** — вверху `app.js`: `MY_TEAMS` и `PRIORITY`.
- **Турниры/листы** — `TOURNAMENTS` в `app.js` (`gid` берётся из ссылки на лист Google).
- **Лига ЛЧБ / команда** — вверху `scrape_lchb.py`: `LEAGUE`, `MY_TEAM`.
- Год турниров и часовой пояс (МСК) — `parser.js` (`YEAR`, `MSK_OFFSET`).

В тех же Google-таблицах есть вкладки CS2 / PUBG / «Мир танков» — их можно добавить в `TOURNAMENTS`.
